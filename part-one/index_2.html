1. Clone the Workshop

First, connect to the workshop server through SSH. Then clone the website repository onto your machine.

git clone YOUR-GITHUB-REPOSITORY-URL
cd devops-workshop

This downloads a copy of the project from GitHub onto your computer.

2. Run Your Website

Once you've cloned the project, move into the project folder and start a simple web server.

cd devops-workshop

python3 -m http.server 8001

Your port number is assigned to you. Replace 8001 with your assigned port.

http://YOUR-PI-IP:8001

Open the address above in your browser. You should now see your copy of the workshop website running from the Raspberry Pi.

💡 Keep this terminal running while you view your website. Press Ctrl + C when you want to stop the server.

2. Make Your First Change

Open index.html and add your name to the Workshop Participants section.

git add index.html
git commit -m "Add my name"
git push

Your change is now saved in Git and pushed to GitHub.
